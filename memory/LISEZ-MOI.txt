Confort+ Mobile — site statique pour conf-plus-mobile.oakcess.fr/cpm/
====================================================================

CONTENU DE CETTE ARCHIVE
  index.html                 page du site (chemins préfixés /cpm/)
  .htaccess                  types MIME .xpi + routage + cache (Apache/OVH)
  static/                    JS + CSS du site React
  downloads/                 orange-confort-plus-6.0.0-alpha.1-android.xpi
  js/, css/, assets/,
  fonts/, _locales/          version serveur de Confort+ (barre d'outils)
  favicon.ico, logo192.png, manifest.json, robots.txt

INSTALLATION SUR OVH
  1. Connecte-toi en FTP/SFTP (ou via l'Explorateur de fichiers OVH).
  2. Place-toi dans la racine web du domaine conf-plus-mobile.oakcess.fr
     (en général www/ ou public_html/ ; sur un multisite OVH, le dossier
     configuré comme racine du domaine).
  3. Crée un dossier nommé exactement : cpm
  4. Décompresse l'archive et envoie TOUT son contenu dans ce dossier cpm/
     (le contenu, pas le dossier zip lui-même).
     ATTENTION : le fichier .htaccess est masqué par défaut — pense à
     activer « afficher les fichiers cachés » dans ton client FTP.
  5. Vérifie l'arborescence finale :
       www/cpm/index.html
       www/cpm/.htaccess
       www/cpm/static/...
       www/cpm/downloads/orange-confort-plus-6.0.0-alpha.1-android.xpi
       www/cpm/js/toolbar.min.js
  6. Ouvre https://conf-plus-mobile.oakcess.fr/cpm/

SI LE .XPI SE TÉLÉCHARGE EN .ZIP OU S'OUVRE COMME DU TEXTE
  C'est que le .htaccess n'a pas été envoyé (ou que mod_rewrite/AddType est
  désactivé). Renvoie le fichier .htaccess à la racine de cpm/.

MISE À JOUR DE L'EXTENSION PLUS TARD
  Remplace uniquement le fichier dans cpm/downloads/ en gardant le même nom,
  ou demande-moi un nouveau paquet complet.

REMARQUE
  Le .xpi n'est pas signé par Mozilla : il s'installe uniquement dans
  Firefox Nightly pour Android avec la collection de modules de débogage
  (procédure détaillée sur la page du site).
